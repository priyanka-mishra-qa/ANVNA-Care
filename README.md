# ANVNA Care - Selenium Automation Project

A Selenium WebDriver practice project created as part of my software testing training.

## About the Project

This project contains Java-based Selenium automation practice for the ANVNA Care healthcare website.

I am using this project to practise browser automation, locating web elements, interacting with web pages, and writing Selenium scripts using Java.

## Website

[ANVNA Care Healthcare Platform](https://anvnacare.alwaysdata.net/)

- Selenium WebDriver
- Maven

- Visual Studio Code
